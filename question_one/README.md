# question 1

calculates water quality index from temperature and turbidity sensor readings and prints the status.

## how to run

```bash
gcc main.c -o main -lm
./main
```

## sample output

```
Temperature: 27.5
Turbidity: 15.0
========================================
Temperature: 27.50
Turbidity 15.00
Calculated Index: 90.00
Water-quality status: Good
========================================
```
